# GiftGauge site

Static marketing, privacy, and support pages for the GiftGauge iOS app.

- `index.html` — landing (`/`)
- `privacy.html` — Privacy Policy (`/privacy`)
- `support.html` — Support (`/support`)

Deployed on Vercel. `vercel.json` enables clean URLs so `/privacy` and
`/support` work without the `.html` extension.

## Deploy

Push to `main`; Vercel auto-deploys the connected project. No build step
(static HTML only).
